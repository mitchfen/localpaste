Tiny app that lets me send strings of text between devices on my home network.  
Useful when I need to send a quick password between devices where I'm not logged into my password manager.

How it stores the data:
1. Stores one string at a time
2. String expires after 10 minutes
2. String is stored as plaintext (risk accepted)
3. String is stored in a file inside the application pod on my home cluster
